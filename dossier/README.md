# Dossier de arquitectura — Nexo CRM

Dossier de arquitectura de software sobre este mismo sistema (Nexo CRM), para la materia de Arquitectura de Software.

## Estructura

- `01-contexto-sistema.md` — Semana 1: contexto del sistema, stakeholders, restricciones. **Completo, mergeado.**
- `02-riesgos-drivers.md` — Semana 2: inventario de riesgos clasificados y drivers arquitectónicos priorizados. **Completo, mergeado.**
- `03-atributos-calidad.md` — Semana 3: matriz de atributos de calidad y escenarios. Borrador — falta priorización final del equipo y los RNF de Ingeniería de Software.
- `04-escenarios-calidad.md` — Semana 4: guía de medición de línea base. Borrador — falta correr la medición real con k6.
- `experimentos/pipeline-load.js` — Script de k6 para la medición de línea base (semana 4).

## Flujo de trabajo

Cada entrega semanal se abre como un Pull Request contra `main` y se revisa/mergea antes de pasar a la siguiente semana.
